# 03. Тест-дизайн и тест-анализ

## Темы

- Классы эквивалентности (Equivalence Class Partitioning).
- Анализ граничных значений (Boundary Value Analysis).
- Диаграмма и таблица состояний и переходов (State & Transition).
- Попарное тестирование (Pairwise Testing).
- Предугадывание ошибок (Error Guessing).
- Тестовые туры.
- Тестовое покрытие и матрица покрытия требований.

## Задания

1. **Классы эквивалентности** — поле ввода логина в сервисе выдачи кредитов.
2. **Граничные значения** — онлайн-калькулятор процентной ставки по кредиту.
3. **Состояния и переходы** — страница авторизации
   (указать ссылку на страницу авторизации сайта компании). Прикрепить скриншот.
4. **Попарное тестирование** — анкета для получения кредита.
5. **Тестовые туры** — минимум 2 тура на основе чек-листа.
6. **Матрица тестового покрытия** — для проверенной страницы.
