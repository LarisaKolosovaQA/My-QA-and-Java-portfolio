## Задание 3. Тестирование документации

Приложение «Найди и иди» ищет магазин и строит маршрут до него.
Геолокация всегда разрешена.

**Скриншот приложения:** прикрепить скриншот.

Техническое задание:

| ID требования | Описание требования |
|---|---|
| REQ-01 | **Поле ввода названия магазина**<br>- принимает любые символы;<br>- содержит плейсхолдер;<br>- плейсхолдер исчезает при вводе;<br>- минимум 2 символа;<br>- сохраняются результаты предыдущих поисков. |
| REQ-02 | **Поле выбора типа магазина**<br>- выпадающее меню: «Продуктовые магазины», «Магазины стройматериалов», «Аптеки» и т.п.;<br>- плейсхолдер «Выберите тип магазина»;<br>- выбранное значение отображается в поле. |
| REQ-03 | **Кнопка «Поиск»**<br>- активна только при заполнении минимум одного поля;<br>- результаты отображаются флажками на карте;<br>- карту можно скроллить и зуммировать. |
| REQ-04 | **Кнопка «Построить маршрут»**<br>- активна, если найден магазин и выбран его флаг или выбран тип магазина;<br>- содержит иконку, надпись и белый фон #fff;<br>- при нажатии фон меняется на #586d73, надпись — на «Отменить маршрут». |
| REQ-05 | **Область карты**<br>- занимает половину экрана;<br>- маршрут строится по условиям REQ-04;<br>- отменяется только кнопкой «Отмена». |
| REQ-06 | **Общие требования**<br>- при повторном открытии показывать незаконченный маршрут;<br>- отключать точную геопозицию при низком заряде аккумулятора. |

**Критерии проверки документации:**

1. Полнота.
2. Однозначность.
3. Непересекаемость.
4. Атомарность.

**Результат:** для каждой ошибки указать фразу, критерий и пояснение,
почему это ошибка.

## Задание 5. Grey-box

Дан доступ к базам данных с информацией о магазинах. Составить чек-лист
проверок приложения «Найди и иди» по методике Grey-box.

> White-box на этом этапе не рассматривается: для него нужно уметь читать код.
