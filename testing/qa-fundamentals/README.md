# QA Fundamentals

Сводный проект по основам тестирования: от базовых понятий до техник тест-дизайна.
Четыре модуля расположены в порядке изучения.

## Модули

1. [Основы тестирования](01-testing-basics/README.md)
   — что такое тестирование, QA/QC, SDLC, принципы тестирования.
2. [Тестовые артефакты](02-test-artifacts/README.md)
   — тест-кейсы, чек-листы, баг-репорты, тест-план.
3. [Тест-дизайн и тест-анализ](03-test-design/README.md)
   — классы эквивалентности, граничные значения, pairwise, тестовые туры, покрытие.
4. [Виды и уровни тестирования](04-types-and-levels/README.md)
   — классификация, уровни, тестирование документации, black/grey box.

## Навыки, которые показывает проект

- понимание места тестирования в жизненном цикле ПО;
- умение составлять тестовые артефакты;
- применение техник тест-дизайна на практике;
- выбор вида и уровня тестирования под задачу.

## Примечание

В заданиях, где требовался конкретный сайт или скриншот, оставлены
заглушки: «указать ссылку на сайт …» и «прикрепить скриншот».
