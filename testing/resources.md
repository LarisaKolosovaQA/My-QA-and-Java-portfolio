# Ресурсы для практики

Бесплатные сайты и тренажёры, на которых можно отработать задания
и подтвердить результат скриншотами.

## Веб, UI и DevTools

| Ресурс | Ссылка | Чем полезен |
|---|---|---|
| Practice Software Testing | https://practicesoftwaretesting.com/ | Демо-магазин, созданный для тестирования: каталог, корзина, оформление заказа, сетевые запросы, API |
| Sauce Demo | https://www.saucedemo.com/ | Логин, каталог, сортировка, корзина. Есть пользователь `problem_user` для поиска дефектов |
| DemoQA | https://demoqa.com/ | Формы, элементы, виджеты, таблицы |
| The Internet | https://the-internet.herokuapp.com/ | Классические тестовые страницы: broken images, slow resources, dynamic content |
| Test Pages | https://testpages.eviltester.com/ | Много отдельных страниц под разные проверки |
| Expand Testing | https://practice.expandtesting.com/ | Веб- и API-практика, бесплатно |
| LambdaTest Playground | https://www.lambdatest.com/selenium-playground/ | Песочница с UI-элементами |

## API и backend

| Ресурс | Ссылка | Чем полезен |
|---|---|---|
| Swagger Petstore | https://petstore.swagger.io/ | REST API с интерактивной документацией |
| JSONPlaceholder | https://jsonplaceholder.typicode.com/ | Простой REST API без авторизации |
| HTTPBin | https://httpbin.org/ | Проверка HTTP-методов, кодов, заголовков |
| DummyJSON | https://dummyjson.com/ | Фейковый REST API: товары, пользователи, заказы |
| Restful Booker | https://restful-booker.herokuapp.com/ | API для практики бронирования |

## Курсы и тренажёры

| Ресурс | Ссылка | Чем полезен |
|---|---|---|
| Stepik | https://stepik.org/ | Бесплатные курсы по тестированию (ищи «Основы тестирования ПО») |
| Test Automation University | https://testautomationu.applitools.com/ | Бесплатные курсы по тестированию и автоматизации |
| Software Testing Help | https://www.softwaretestinghelp.com/ | Статьи и гайды по ручному тестированию |

> Для заданий с DevTools лучше всего подходит **Practice Software Testing**:
> там есть каталог, корзина, cookies, сетевые запросы и разные состояния интерфейса.
