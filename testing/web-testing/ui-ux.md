# UI/UX-тестирование

Сайт: _указать ссылку на сайт магазина или компании._
Эталонный макет: _указать ссылку на макет (например, Figma)._

## Задание

1. Сравнить макет с реализованным сайтом (макет считается эталоном).
2. Найти отличия в дизайне, шрифтах, отступах и других элементах.
3. Оформить минимум 3 баг-репорта.

**Прикрепить скриншоты** найденных отличий.

## Если макета нет

Провести UI-аудит по чек-листу: консистентность шрифтов и цветов, отступы,
состояния кнопок, адаптивность, читаемость, навигация. Найденные проблемы
оформить как минимум 3 баг-репорта.
