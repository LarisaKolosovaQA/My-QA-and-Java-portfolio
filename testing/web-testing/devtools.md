## Задание

### 1. Изменение раздела в хедере

Изменить название любого раздела в хедере страницы через HTML в DevTools.
Убедиться, что изменение видно на странице.

**Прикрепить скриншот.**

### 2. Неиспользуемые CSS и JS

Найти в DevTools все неиспользуемые CSS и JS в вёрстке.

**Прикрепить скриншот** со всеми найденными неиспользуемыми элементами.

## Что изучить в DevTools

- Elements — HTML и CSS.
- Console — ошибки JavaScript.
- Network — запросы, ответы, коды состояния, время загрузки.
- Application — cookies, local storage, session storage.
- Performance — скорость загрузки и узкие места.
- Lighthouse — аудит производительности и доступности.
