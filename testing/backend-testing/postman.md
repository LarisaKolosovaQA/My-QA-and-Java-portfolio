# Postman

## Задание

1. Установить Postman и зарегистрировать аккаунт.
2. Изучить:
   - настройку окружения;
   - создание коллекций;
   - создание запросов в коллекциях;
   - добавление сниппетов;
   - запуск автотестов для коллекции.
3. Выбрать публичный API: _указать ссылку._
4. Настроить окружение и создать коллекцию минимум из 3 запросов
   с разными HTTP-методами.
5. Добавить к запросам сниппеты, выполнить их и проанализировать ответы.
6. Экспортировать коллекцию в `.json` и проверить, что она импортируется
   без дополнительных настроек.
7. Загрузить экспортированный файл в файловый сервис:
   _указать ссылку._
